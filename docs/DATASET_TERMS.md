# Dataset access and terms

The official AVSBench project page describes the object dataset as research-only under CC BY-NC 4.0 and links CSV/video-ID metadata and annotated masks. The official repository says AVSBench-object/semantic data may be requested by email; its project page separately says to email the maintainers with a name and institution for processed videos and audio. This workspace has not acquired or validated an AVSBench release. The repository's Apache 2.0 software license does not replace dataset terms. Before use, verify the release version, attribution, source-video rights, and access process at the [AVSBench project page](https://opennlplab.github.io/AVSBench/) and [official repository](https://github.com/OpenNLPLab/AVSBench). A dataset license statement does not establish rights for every source clip. Do not redistribute clips, masks, or derived checkpoints without authorization.

The [AVATAR Hugging Face dataset card](https://huggingface.co/datasets/mipal/AVATAR) declares CC BY 4.0 and provides direct public downloads. Attribute the dataset authors and cite the ICCV 2025 paper. The card does not clarify all rights in the underlying video/audio source media, so check source-platform and third-party terms before use, especially for redistribution or commercial deployment. SoundTrace downloads and generated masks are local-only and must not be committed to this repository.
