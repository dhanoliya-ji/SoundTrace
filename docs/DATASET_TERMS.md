# Dataset access and terms

The official AVSBench page describes the object dataset as research-only and under CC BY-NC 4.0. The current official repository directs users to request AVSBench-object access using its application form or by contacting the maintainers; access is not bundled or downloaded automatically. The repository's Apache 2.0 software license does not replace dataset terms. This workspace does not contain the dataset. Before use, verify the current release terms, attribution, source-video rights, and access process at the [AVSBench project page](https://opennlplab.github.io/AVSBench/) and [official repository](https://github.com/OpenNLPLab/AVSBench). A dataset license statement does not establish rights for every source clip. Do not redistribute clips, masks, or derived checkpoints without authorization.

The [AVATAR Hugging Face dataset card](https://huggingface.co/datasets/mipal/AVATAR) declares CC BY 4.0 and provides direct public downloads. Attribute the dataset authors and cite the ICCV 2025 paper. The card does not clarify all rights in the underlying video/audio source media, so check source-platform and third-party terms before use, especially for redistribution or commercial deployment. SoundTrace downloads and generated masks are local-only and must not be committed to this repository.
