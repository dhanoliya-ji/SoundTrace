# Experiment tracking

The CLI writes config path, seed, manifest hash, source revision, runtime details, split fingerprint, variant, checkpoint, duration, validation score, per-example test IoU/F1, and aggregate metrics to JSON/Markdown reports. IoU follows the official AVSBench empty-mask convention. Reports include threshold F1 at 0.5 and the AVSBench max F-measure protocol (255 thresholds, beta-squared 0.3, empty masks excluded, averaged by source video). Training selects checkpoints using validation examples. Standalone evaluation and robustness commands score only the held-out test split and stop if it is empty; they never fall back to scoring all manifest rows. Manifest validation rejects mixed split metadata and source videos assigned to multiple splits.

Use `python -m soundtrace.cli study --config configs/baseline.yaml --seeds 7,17,27` for a paired multi-seed comparison. The runner uses the same seed, source-video split, manifest, and training parameters for baseline and gated variants, retains each checkpoint, and reports the mean and sample standard deviation of paired test-IoU differences. A small number of seeds is descriptive, not proof of statistical significance.

The dashboard lists saved reports. The comparison endpoint pairs baseline and gated training runs only when manifest hash, seed, and exact source-video split fingerprint match. This does not establish equivalence of optimization settings or prove statistical significance; inspect each report before drawing conclusions. Keep artifacts outside Git. No real-data experiment has been run in this workspace.
