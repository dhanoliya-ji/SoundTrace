# Architecture

Decoded RGB frames enter a spatial convolutional visual encoder. Audio can be a timestamp-centered waveform decoded by FFmpeg for general video inputs or an official five-clip AVSBench log-mel feature for dataset runs. Dedicated compact 1D and 2D audio encoders map either input to a shared channel vector. The audio feature is broadcast over the visual feature map. Baseline fusion concatenates them; gated fusion predicts per-channel audio contribution and uses it in the segmentation path. A convolutional decoder returns full-resolution binary logits. The gate is an internal learned coefficient and is not calibrated reliability.

The current frontend API returns one middle-frame mask. API job state is in process memory and disappears on restart. These are deliberate prototype boundaries; durable persistence and complete video timelines remain follow-up engineering work. The AVSBench adapter follows the official public S4/MS3 loader paths but still needs inspection against an acquired release.
