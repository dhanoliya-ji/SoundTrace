# Responsible use

Audio and video can contain identifiable people, private speech, homes, and sensitive events. Prefer local processing, obtain consent and lawful rights, limit access and retention, and delete uploads. The local API deletes temporary uploads after inference and does not retain by default. Dataset access does not confer rights to source videos or redistribution. Never publish restricted clips or masks. Predictions are uncertain research outputs and must not be used to identify speakers, infer intent, or make consequential decisions.
